# Локальный Obsidian Multi-Agent RAG

Локальный исследовательский агент объединяет личные заметки Obsidian и публичный веб-поиск. Supervisor на LangGraph выбирает между двумя специалистами: `obsidian_expert` и `web_researcher`. Ответы выдаются потоково, а источники должны быть явно указаны.

## Архитектура

```text
Запрос
  ↓
Supervisor
  ├── obsidian_expert → FAISS → Obsidian notes
  └── web_researcher → DDGS → browse_page
  ↓
Ответ с разделением источников и выводов
```

Краткая память текущего диалога реализована через `MemorySaver`. Для долговременной памяти предусмотрена опциональная интеграция с [Memanto](https://github.com/moorcheh-ai/memanto). Включение Memanto не обязательно для базового запуска.

## Требования

Нужны Python 3.11–3.12, [Ollama](https://ollama.com/), локальная модель чата и локальная embedding-модель. Для первого запуска:

```bash
ollama pull llama3.2
ollama pull nomic-embed-text
```

Затем установите зависимости:

```bash
cd /home/ubuntu/obsidian-multi-agent
cp .env.example .env
# Измените OBSIDIAN_VAULT_PATH в .env
sudo uv pip install -e .
```

Если `uv` недоступен, используйте виртуальное окружение и `pip install -e .`.

## Запуск

```bash
cd /home/ubuntu/obsidian-multi-agent
python3 -m src.main
```

Или:

```bash
obsidian-agent
```

Команды внутри CLI:

```text
/help      показать команды
/reindex   принудительно пересобрать FAISS-индекс
/sources   показать правила источников
/exit      завершить работу
```

При `WATCH_OBSIDIAN=true` изменения в Markdown-файлах автоматически запускают консервативную пересборку индекса. Это медленнее точечного удаления, но устойчивее между версиями FAISS и LangChain.

## Memanto

Memanto используется как **долговременная память агента**, а не как замена индексу Obsidian. FAISS отвечает на вопрос «что содержится в заметках», тогда как Memanto может хранить устойчивые факты, предпочтения, решения, ошибки и знания между независимыми сессиями.

Для включения:

```bash
# В .env
MEMANTO_ENABLED=true
MEMANTO_AGENT_ID=local-obsidian-researcher
MOORCHEH_API_KEY=your_key_or_local_backend_config
```

Перед этим установите и настройте локальный Memanto в on-prem режиме согласно его [официальной документации](https://github.com/moorcheh-ai/memanto). Если Memanto не настроен, оставьте `MEMANTO_ENABLED=false`.

Важно разделять уровни памяти:

| Слой | Назначение |
|---|---|
| FAISS | Семантический поиск по файлам Obsidian |
| LangGraph `MemorySaver` | Состояние текущего conversation thread |
| Memanto | Долговременные факты, решения, предпочтения, конфликты и воспоминания между сессиями |

## Безопасность и ограничения

Веб-инструмент принимает только `http` и `https`, проверяет HTTP-ошибки и ограничивает размер извлечённого текста. Однако это не sandbox веб-страниц: не передавайте агенту секреты и не разрешайте ему автоматически выполнять команды из найденного контента.

Агент может ошибиться в маршрутизации или интерпретации источников. Для критических сведений проверяйте исходные заметки и URL вручную. Формат источников в ответе — `[OBSIDIAN-N]` для локальных фрагментов и URL для внешних страниц.

## Структура

```text
src/
├── agent.py       # Supervisor и два специализированных агента
├── config.py      # настройки из .env
├── indexer.py     # FAISS + Markdown + Watchdog
├── memory.py      # необязательная Memanto-интеграция
├── main.py        # CLI и streaming
└── tools.py       # Obsidian search, web search, page reader
```

## Gradio-интерфейс

Для запуска локального графического интерфейса:

```bash
python3 -m src.gradio_app
```

После запуска откройте `http://127.0.0.1:7860`. Можно изменить адрес и порт:

```bash
python3 -m src.gradio_app --host 127.0.0.1 --port 7860
```

Интерфейс содержит:

- чат с потоковой выдачей ответа;
- поле `ID сессии` для сохранения контекста отдельного диалога;
- панель источников Obsidian и веб-ссылок;
- индикатор количества индексированных фрагментов;
- кнопку `Переиндексировать Obsidian`;
- автоматическое обновление индекса через Watchdog.

Gradio работает только локально, если оставить `GRADIO_HOST=127.0.0.1`. Не устанавливайте `0.0.0.0`, если не хотите открывать агент в локальной сети.
